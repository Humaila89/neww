# Little Lemon - Capstone Project

Simple front-end project for the Little Lemon restaurant capstone.

## Features
- Responsive layout and styling
- Accessible reservation booking form with client-side validation
- Bookings saved to `localStorage` (for demo purposes)

## Run locally
You can open `index.html` directly in a browser, or serve it with a simple static server:

```bash
# from project folder
npx http-server . -o
```

## Submission for peer review
1. Create a GitHub repository and push this project.
2. On the course submission page click **My submission**.
3. Provide a project title (e.g. "Front-end developer capstone project").
4. Paste your repository URL and click **Preview**, then **Submit**.

## Notes for reviewers
- Check accessibility labels and keyboard focus for the form.
- Booking form uses HTML5 validation and a small JS validator in `script.js`.
- No automated tests included; you can add tests using Jest or similar.
